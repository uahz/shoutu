# 守土 · 城市治理模拟

> 一座城，一场任期，一次次设身处地的抉择。
> 架空世界 · 虚构创作 · 单文件 HTML 游戏

![守土](icon.png)

**《守土》**是一款原创架空城市治理模拟游戏：你走马上任，从镇长做起，在财政、城建、人事、监察、产业之间辗转腾挪，历经年度考核逐级晋升——直到封疆一方，或者中途落马。

网页版开箱即玩，桌面版（Windows exe）双击即用，零依赖、免安装。

## 玩法一览

| 系统 | 内容 |
| --- | --- |
| 财政 | 税收结构、三保优先序（保工资→保运转→保基本民生）、专项债 vs 城投债、化债五路径、收支瀑布、赤字归因 |
| 土地财政 | 出让住宅用地换一次性出让金，开发商随后动工；房价指数、市场热度、年度出让指标 |
| 城建 | 16×10 规划图，13 种用地（住宅/商业/工业/市政/生态），成本随规模递增 |
| 人事 | 编制招录、四口干部任命、机构改革、干部轮岗 |
| 民生 | 教育/医疗/宜居三慢变量，民生支出强度三档 |
| 产业 | 三档招商引资、企业生命周期、产业扶持政策 |
| 监察 | 廉洁度、问题线索、审计倒查、责任档案终身留存、灰色融资的代价 |
| 舆情 | 舆情热度系统：欠薪、赤字、积案推高舆情，新闻发布会主动降温，过高触发上级约谈 |

| 晋升 | 镇长→县长→区长→市长→封疆，年度五维考核（增长/财政/民生/民意/廉洁），盖印定档 |

## 运行 / 构建

**网页版**：直接用浏览器打开 `index.html` 即可，无需服务器。

**桌面版构建**（Windows）：

```bat
build_exe.bat
```

或手动执行：

```bash
pip install -r requirements.txt
pyinstaller --onefile --windowed --name Shoutu --icon icon.ico --add-data "index.html;." main.py
```

产物在 `dist/Shoutu.exe`。

**平衡性模拟**（Node.js 无头回归）：

```bash
node _sim.js safe    # 稳健守法策略 × 40 局
node _sim.js random  # 随机贪玩策略 × 40 局
```

## 技术栈

- **游戏本体**：纯原生 HTML/CSS/JS 单文件，零依赖，约 1700 行
- **桌面壳**：Python + pywebview（Edge WebView2 渲染），PyInstaller 打包为单文件 exe
- **响应式**：<768px 移动端 / 768–1024px 平板 / >1024px 桌面三端自适应，实时切换不丢状态
- **视觉**：「墨韵公文」主题——墨绿底 × 宣纸 × 朱砂印章 × 描金，楷体印文
